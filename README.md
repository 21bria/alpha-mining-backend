# alpha-mining-backend

Alpha Mining Backend is a scalable multi-tenant backend system built with Django and Django REST Framework, designed for enterprise mining operations. It provides APIs for production tracking, geology data management, inventory control, and real-time analytics.

## 🚀 Features

- Multi-tenant architecture (django-tenants)
- Production data management (Mining Operations)
- Geology & CRM data processing
- Inventory & stockpile tracking
- Real-time analytics & dashboard support
- Role-based access control (RBAC)
- API-first design (RESTful)

## 🏗️ Tech Stack

- Python 3.x
- Django 5.1.8
- Django REST Framework
- PostgreSQL (with multi-schema support)
- Redis & Celery (for background jobs)
- Pandas (data processing)
