Penjelasan untuk 2 metrik :

1. Avg MT
Arti: rata-rata muatan/tonase per barge.

Rumus:
Avg MT = Total Ore / Total Barge

Contoh Excel:
Barge	Total Tonnage
BG001	20.000
BG002	15.000
BG003	25.000
Total Ore = 60.000
Total Barge = 3

Avg MT = 60.000 / 3
Avg MT = 20.000 MT

Formula Excel:
=SUM(B2:B4)/COUNTA(A2:A4)

2. Avg Loading Time

Arti: rata-rata durasi loading per barge, dalam jam.

Rumus per barge:

Loading Time = End Loading - Start Loading

Karena Excel hasilnya dalam format hari, kalikan 24 agar jadi jam:

Loading Time (jam) = (End Loading - Start Loading) * 24

Rumus rata-rata:

Avg Loading Time = Total Loading Time / Total Barge

atau:

Avg Loading Time = AVERAGE(Loading Time tiap barge)

Contoh Excel:

Barge	Start Loading	End Loading	Loading Time
BG001	08:00	14:00	6
BG002	10:00	18:00	8
BG003	07:00	16:00	9

Avg Loading Time = (6 + 8 + 9) / 3
Avg Loading Time = 7,67 jam

Formula Excel Loading Time:

=(C2-B2)*24

Formula Excel Avg Loading Time:

=AVERAGE(D2:D4)

Kalau start/end ada tanggal + jam, formula tetap sama:
=(C2-B2)*24
